# 🛍️ Store & Community Web Portal

A multi-page responsive front-end website featuring an interactive product catalog, store directory, user discussion forum, and contact portal built with pure HTML5, CSS3, and JavaScript.

---

## 📌 Features

* **Home Page (`index.html`):** Modern landing page with navigation and hero section.
* **Products Showcase (`products.html`):** Grid layout showcasing catalog items with dedicated styling[cite: 5].
* **Store Locator (`store.html`):** Directory displaying store locations and availability[cite: 5].
* **Community Forum (`forum.html`):** Discussion board interface for user interaction[cite: 5].
* **Contact Us (`contact-us.html`):** Interactive contact form with input validation via vanilla JavaScript[cite: 5].
* **Design & Assets:** Integrated custom fonts, mockups, and UI design assets[cite: 5].

---

## 🛠️ Tech Stack

* **Markup:** HTML5[cite: 5]
* **Styling:** CSS3 (Flexbox/Grid layout, responsive styling)[cite: 5]
* **Scripting:** JavaScript (Vanilla JS)[cite: 5]
* **Design Tools:** Figma & UI Mockups[cite: 5]
